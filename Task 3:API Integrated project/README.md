# 📝 Alfido Tech — Modern Glassy To-Do List Application

A **modern, glassy, and feature-rich To-Do List app** built using **HTML, CSS, and JavaScript**.  
This project combines minimal UI design with advanced interactivity — perfect for practicing **frontend development** skills at Alfido Tech.

---

## 🌟 Features

✅ **Add, Edit, Delete Tasks** — Create tasks easily and modify them anytime.  
✅ **Mark as Complete** — Track progress visually with a smooth progress bar.  
✅ **Set Due Dates & Priorities** — Choose task priority (Low, Medium, High) with color badges.  
✅ **Dynamic Filters** — View all, active, or completed tasks instantly.  
✅ **Search & Filter** — Quickly find tasks by keyword.  
✅ **Drag and Drop Reordering** — Reorder tasks interactively.  
✅ **Persistent Storage** — Tasks are saved in browser **LocalStorage** automatically.  
✅ **Export / Import Tasks** — Backup or share your to-do list in JSON format.  
✅ **Light / Dark Mode** — Switch between glassy themes with a single click.  
✅ **Progress Tracker** — Displays total, completed, and pending tasks with a glowing bar.  
✅ **Responsive UI** — Fully adaptable design for mobile, tablet, and desktop.

## 🪟 Design Highlights

✨ **Glassy (Frosted Glass)** interface using `backdrop-filter: blur()`  
💡 **Neon gradient hover effects** — cyan & pink reflections  
🌓 **Light and Dark modes** with persistent theme memory  
📱 **Responsive layout** that adapts beautifully across all devices
